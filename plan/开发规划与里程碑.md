# 钟毓在线教育系统（ZhyOnlineEdu）开发规划与里程碑

> 依据《技术开发计划书》（同目录）第十七章，作为执行层任务分解与验收基线。

## 一、关键路径

`M0 upsert 契约 → M1.2 适配层 v2 → M2.4 沙箱转码 / M2.5 播放+进度网关 → M3 插件 SDK 收窄 → M4.1 安全专项`。
M0 方言 spike 直通 M5 国产化段。

## 二、里程碑明细

### M0 · 技术验证 Spike

| 任务 | 产出 | 验收 |
